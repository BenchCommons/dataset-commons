# dataset-commons

Small shared datasets (texts, graphs, numbers) used as common inputs by the BenchCommons catalogs.

Datasets follow the input contract owned by [tools-dataset](https://github.com/BenchCommons/tools-dataset): deterministic sizes, checksums, versioned releases.

Status: starting. The first spec is being defined in issue #1. Specs live in `docs/specs/<NNN>-<feature>/`.
